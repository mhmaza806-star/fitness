# FitFusion

A modern fitness landing page and wellness dashboard built as a responsive web app.

## Features
- Strong hero section and modern fitness branding
- Program cards for strength, fat burn, and mobility
- Nutrition and habit guidance sections
- Interactive BMI calculator
- Pricing section and polished responsive layout

## Run locally
Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — main page structure
- `styles.css` — styling and layout
- `script.js` — BMI calculator and mobile menu logic
